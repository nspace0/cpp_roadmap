# Перенос прогресса всех карт

Функция находится на странице **«Все карты» → «Одна резервная копия для всех карт»** (`maps/#backup`). Она необязательна: прежние отдельные экспорты и импорты работают по своим старым правилам. Единый экспорт не меняет прогресс и не отмечает задания выполненными.

## Что сохраняется

| Данные | Прежний ключ localStorage |
|---|---|
| C/C++, заметки модулей, практика, критерии, недели | `cpp-roadmap-offline-v1` |
| NMS, планы, результаты ревью и книжные упражнения | `nms-development-roadmap-v1` |
| Математика, физика, история, астрономия, assembly, cpp-tools, ROS, электроника, радиотелескоп и его ПО | `hands-on-<id>-v1` |
| Журнал пробелов каждого из 12 направлений, включая собственные темы | `roadmap-scope-<id>-v1` |
| Карточки собеседования | `cpp-interview-progress-v1` |
| Покупки, резерв бюджета и заметки этапов сборки радиотелескопа | `radio-build-progress-v1` |

Всего 26 независимых разделов. Пустые, ещё не созданные хранилища не придумываются. Тема оформления, сторонние ключи сайта и прежние служебные `*-before-import` не включаются. Незаписанный текст открытой формы не входит в localStorage: сначала нажми её кнопку сохранения.

## С одного компьютера или браузера на другой

1. На исходном устройстве открой **тот адрес и тот профиль браузера, где видны твои отметки**. Сохрани открытые формы и закрой остальные вкладки карт.
2. Открой «Все карты», нажми **«Скачать единый бэкап»**. Проверь наличие JSON в загрузках и число разделов в сообщении. Файл содержит заметки в открытом виде; не публикуй его в GitHub вместе с исходниками.
3. Перенеси файл на другой компьютер: например, через свой накопитель. Windows, WSL и Kubuntu используют один формат JSON. Сборочные каталоги лабораторий в него не входят.
4. На целевом устройстве открой нужный сайт, затем **«Проверить файл для восстановления»**. До окончания проверки и твоего подтверждения ничего не записывается.
5. Просмотри список: «Будет добавлен», «Будет заменён целиком», «Без изменений». Разделы, отсутствующие в файле, сохранятся. **Включённый раздел заменяется целиком, а не объединяется по датам**: отсутствующие записи внутри него будут удалены. Для частичного переноса можно выбрать прежний отдельный JSON одной карты.
6. По умолчанию включено **«Сначала сохранить прежнее состояние»**. Нажми «Скачать прежнее состояние» и проверь, что файл действительно сохранился. Если копия уже есть, можно снять опцию; решение остаётся за тобой.
7. Нажми **«Восстановить после подтверждения»** и подтверди замену. «Отмена» и отказ в диалоге ничего не меняют. Открой карты заново и проверь свои заметки.

Для возврата прежнего содержимого используй скачанный до импорта файл. Его отсутствующие разделы также не удаляют новые хранилища: единый импорт намеренно не является командой «очистить всё». Если нужно убрать добавленные после копии данные, это отдельное действие, которое следует делать средствами соответствующей карты после экспорта.

## Отдельные хранилища

GitHub Pages, Vercel, `localhost`, другой профиль и приватное окно — разные места хранения. Бэкап страницы может читать только свой origin, не соседний домен или другой браузер. Даже разные проекты одного origin могут делить localStorage; здесь экспортируется только белый список известных ключей.

Скачанные HTML через `file://` в разных браузерах могут иметь отдельные хранилища для каждого пути. Единая копия на опубликованном сайте не видит эти файлы. Сначала сделай отдельный экспорт в каждом таком HTML и импортируй его через проверку на целевом сайте; затем скачай единый JSON. Автоматической синхронизации и отправки заметок на сервер нет.

## Совместимость и защита

- Контейнер: `{format:"cpp-roadmap-backup",version:1,exportedAt,entries:[{key,value}]}`. `value` — исходная JSON-строка localStorage. Форматы, поля, статусы, даты и ключи разделов не переименовываются и не нормализуются при переносе.
- Поддержаны все опубликованные отдельные JSON версии 1, включая NMS до добавления поля `books`. Новый контейнер ранее не существовал; версия 0 и будущие версии отклоняются с объяснением. Неизвестные направления или идентификаторы не отбрасываются молча: нужен сайт, понимающий эту версию курса.
- Проверяются формат, размер (32 МиБ), вложенность, белый список ключей, повторы разделов, идентификаторы, значения, доказательства и зависимости принятых заданий. Используются валидаторы самих учебных карт и компактная схема, генерируемая из текущих исходников. Записи с опасными служебными именами полей отклоняются.
- Если хотя бы один раздел некорректен, весь импорт отклоняется до первой записи. Экспорт повреждённого локального значения сохраняет его исходные байты и выдаёт предупреждение для ручного восстановления; такой файл нельзя автоматически восстановить до исправления.
- Перед записью проверяется, не изменился ли прогресс с момента предварительного просмотра. При обычной ошибке `setItem` (например, квота) выполняется откат. Если и откат отклонён браузером, сообщение прямо перечисляет проблемные ключи. Скачанная копия нужна и в этом случае.
- localStorage не поддерживает транзакцию нескольких ключей. Сбой питания, аварийное закрытие и одновременная запись другой вкладкой не дают гарантии атомарности. Закрой другие вкладки перед импортом. Обновлённые редакторы при событии изменения своего хранилища блокируют дальнейший ввод и предлагают перезагрузку. Уже открытая старая версия сайта такой защиты не имеет.

## Автоматические проверки

Из корня репозитория, Node.js 22:

```sh
node --test learning/progress-backup/check.mjs
node --test learning/check.mjs learning/check-developer-courses.mjs learning/nms/books-check.cjs learning/radio-build/check.mjs
```

Проверяются все 26 разделов, точное восстановление строк, отсутствие записи при экспорте/отмене, неполный и пустой архив, старые JSON, неизвестные версии/ID, повреждённый раздел, прототипные поля, превышение лимита, конкурентное изменение и откат квоты. Проверки используют синтетическое хранилище.

Настоящие браузеры с отдельными временными профилями:

```sh
cd learning/progress-backup/browser
npm ci
npx playwright install --with-deps chromium firefox
npm test
```

Тест запускает локальный HTTP-сервер только на loopback, скачивает копию в Chromium и восстанавливает её в Firefox, проверяет отмену, резервную копию назначения, старый отдельный формат, открытие исходных карт, блокировку устаревшего редактора и ширину мобильного макета. Артефакты: `results/report.json` и PNG. Личные браузеры и реальный прогресс пользователя не используются.
