РАДИОТЕЛЕСКОП — ПРАКТИЧЕСКИЙ КОМПЛЕКТ, 2026-10-18

Распакуй весь ZIP и открой index.html из родительской папки.
PDF, SVG и программы находятся в files. Для чтения интернет не нужен;
внешние первоисточники, установка зависимостей и карты обучения требуют сети.
Ссылка «Скачать ZIP» в распакованной копии неприменима: архив уже у тебя.

Начало: RB01 (закупка только первого стенда) и RB02 (драйвер/USB).
Без оборудования: в отдельное Python-окружение установи numpy и matplotlib.
Из files выполни:
  python make_test_signal.py synthetic.cu8
  python iq_spectrum.py synthetic.cu8 --fs 2400000 --fc 1420000000 --out synthetic-result
Используй python соответствующего окружения (.venv/bin/python на Linux,
.\.venv\Scripts\python.exe на Windows). Настройка окружения описана в RB07.
Ожидается искусственный тон около 1420.350 MHz. Это не наблюдение водорода.

Фактические цены, отметки и заметки вводятся только тобой. Они хранятся
в браузере отдельно от основной карты. Экспортируй JSON перед переносом
между компьютерами, очисткой браузера или сменой локальной/онлайн-версии.
Поведение localStorage для file:// зависит от браузера; если сохранение
недоступно, используй экспорт. Сайт не передаёт записи на GitHub или в чат.

Приведены расчёты и проверки ПО на искусственных данных. Физическая сборка,
чувствительность и обнаружение H I на этом комплекте не испытаны автором
руководства. Не отмечай аппаратные критерии по одному прочтению текста.
