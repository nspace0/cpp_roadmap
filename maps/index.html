Сохрани отметки, заметки, планы, книжную практику, карточки собеседования, пробелы и сборку радиотелескопа в один JSON. Экспорт читает только данные этого сайта в этом браузере. Автоматической синхронизации нет.

Предварительная проверка

    Включённые разделы заменяются целиком. Записи внутри них, которых нет в файле, будут удалены. Отсутствующие разделы сохранятся.

    Что входит в копию и какие есть ограничения

    12 направлений и их журналы пробелов, карточки собеседования, книжные упражнения NMS и комплект радиотелескопа. Ключи и отдельные JSON сохраняют прежний формат. Настройки темы и старые автоматические копии before-import не включаются.

    GitHub Pages, Vercel, localhost, другой профиль и скачанный HTML имеют отдельные хранилища. Делай экспорт там, где видны нужные записи. Локальные HTML с разными file:// адресами могут требовать отдельных экспортов. Файл содержит твои заметки — передавай его только тем, кому хочешь их показать.

    Повреждённые данные можно скачать для ручного восстановления, но импорт отклонит их до записи. При обычной ошибке записи выполняется откат; закрытие браузера или сбой питания во время записи не дают гарантии атомарности. Сохрани прежний JSON.

    Где я сейчас?

    Отметки на карточках читаются из этого браузера. Внутри карты есть текущая задача, заметки и экспорт прогресса. В новых картах: теория → практика → проверка → исправления → принятый результат.

    Выбери один основной результат на месяц и 1–3 ближайших задания. Недельный бюджет делится между всеми картами — одни и те же часы не складываются несколько раз.

    Что я ещё не изучил?

    В любой карте открой «Что ещё изучить». Там есть ограничения каждого урока и отдельные направления углубления. Выбери нужные под свою цель, добавь найденные пробелы и запиши, чем проверил результат.

    Вкладки покрытия показывают, какие разделы разобраны, где есть только введение и что требует отдельного курса. В математике есть сверка с исходной картой Talal Alrawajfeh; в ROS и электротехнике — с заданиями буткемпа.
