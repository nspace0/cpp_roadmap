## Карта и встроенный учебник

75 модулей и 381 тема: от подготовки к отбору на C++ до системной разработки, Qt, сетей, электроники, ЦОС и инженерной ответственности за систему.

Нажмите на модуль, затем на название темы или **«Открыть урок»**. В каждой теме есть теория на русском, разобранный пример, самостоятельная задача с разбором, вопросы с ответами, типичные ошибки и дополнительные ссылки. Язык источника указан: **РУС** или **ENG**. Содержание учебника доступно без перехода на другие сайты; интернет нужен только для внешних источников.

Поиск на карте находит и названия тем, и понятия внутри уроков. Внутри урока доступны переходы по разделам и между соседними темами. Адрес с `#lesson=1.2` можно сохранить в закладки. Кнопка печати в уроке включает ответы в печатную версию. Практическое задание всего модуля — на вкладке «Практика».

Отметки и заметки сохраняются в текущем браузере. Обновление учебника сохраняет прежние коды тем и формат прогресса `cpp-roadmap-offline-v1`. Для переноса или резервной копии используйте **«Мои файлы» → «Экспорт прогресса в JSON»** либо **«Скачать HTML с прогрессом»**. Скачанный HTML содержит все уроки и работает самостоятельно, без аккаунта, CDN и серверных запросов. Автоматической синхронизации между устройствами нет.

Время чтения встроенного урока — ориентир для первого разбора. Часы в исходном плане включают более глубокое изучение и закрепление; уровень навыка подтверждается самостоятельной практикой. Встроенный исходный DOCX — предыдущий план, новые уроки находятся в самой карте.

## Подготовка к YADRO

[Открыть ветку курса](https://nspace0.github.io/cpp_roadmap/#route=yadro).

Ветка **«Курс YADRO · C»** дополняет исходную карту 10 модулями и 37 уроками Y0–Y9. Она составлена по предоставленной пользователем программе курса «Системное программирование с использованием языка C» и диаграмме распределения тем. Это самостоятельные учебные объяснения, а не официальный комплект материалов YADRO.

- Входная диагностика C и Linux-лаборатория; выбранная подготовка на 48–60 часов.
- ELF, компоновка, ABI, GDB/binutils, UB и диагностика.
- Linux, процессы, IPC, виртуальная память, C11 atomics и MMIO.
- RISC-V, trap, OpenSBI, загрузка, Sv39/TLB и гипервизор.
- Производительность, QEMU, gem5, контейнеры, DMA, Linux/Zephyr и Buildroot.
- Итоговый C-проект, review и защита решений.

В блоке «План подготовки и программа курса» доступны четыре этапа быстрого входа, рекомендуемая последовательность октября–мая и соответствие всем пунктам присланной программы. Распределение процентов взято из изображения пользователя. Календарь рекомендательный: фактический порядок лабораторных определяет преподаватель. Полный объём новой ветки оценивается в 203–322 часа и включает быстрый вход; знакомую базу можно пропускать после практической проверки.

Исходные 344 урока и их идентификаторы сохранены. Общее число тем выросло, поэтому процент общего прогресса может уменьшиться при тех же отметках. Ветка YADRO имеет отдельный счётчик. Связанные уроки доступны прямо из читателя. Новые материалы тоже входят в автономный HTML; внешние ссылки требуют интернета.

Пользовательские C-примеры и структура материалов проверены сборкой и локальными проверками. Полные сборки Buildroot/gem5, загрузка модулей ядра и работа Zephyr на оборудовании в рамках обновления не выполнялись; соответствующие уроки содержат требования к стенду.

## Сборка и обновление GitHub Pages

Для локальной сборки нужен Node.js с npm. В каталоге `source`:

```sh
npm install
npm run check
npm run build
```

Сборка создаёт одинаковые `index.html` и `C_CPP_Roadmap_Offline.html` в корне репозитория и в `source/dist/`. GitHub Pages публикует ветку `main`, каталог `/ (root)`. Файл `.nojekyll` сохраняйте в корне.

Перед локальными изменениями подтяните актуальную ветку: `git pull --ff-only`. Если команда сообщает о расхождении истории, сначала разберите различия; не заменяйте рабочую ветку старой копией через force push.

Структура исходников:

- `source/data/roadmap.json` — исходная карта и постоянные коды тем;
- `source/data/lessons.json` — встроенные уроки по кодам тем;
- `source/data/module-lessons.json` — введения и итоговые задания модулей;
- `source/data/yadro-course.json` — подготовка, месяцы и покрытие программы YADRO;
- `source/app/yadro-panel.tsx` — план и прогресс ветки курса;
- `source/app/lesson-reader.tsx` — интерфейс чтения;
- `source/assets/lessons.css` — оформление уроков и печати;
- `source/app/local-progress.ts` — совместимое локальное сохранение;
- `source/build.mjs` — автономная сборка двух точек входа.

Уроки написаны как самостоятельные учебные объяснения и примеры. Внешние статьи и документация остаются у их авторов; они доступны по дополнительным ссылкам.
