ИСХОДНИКИ АВТОНОМНОГО C++ ROADMAP

Для использования готового HTML ничего из этого устанавливать не нужно.

Редактирование и сборка:
1. Установить Node.js с npm.
2. В этой папке выполнить npm install.
3. npm run check — проверка TypeScript.
4. npm run build — получить dist/C_CPP_Roadmap_Offline.html.

Структура:
• data/roadmap.json — модули, подтемы, часы, сложность, задания и источники.
• app/map-config.ts — размещение модулей на ветках карты.
• app/roadmap.tsx — интерфейс карты, тем, недель и материалов.
• app/local-progress.ts — локальное сохранение, валидация и перенос прогресса.
• app/offline-files.tsx — экспорт/импорт и переносимая HTML-копия.
• assets/styles.css — готовые стили, включая используемые компоненты.
• assets/offline.css — дополнительные стили автономного режима.
• assets/C_CPP_roadmap.docx — исходный документ; встраивается в HTML.
• components, hooks, lib — используемые компоненты интерфейса.
• build.mjs — сборка JavaScript и встраивание всех ресурсов в один HTML.

assets/styles.css уже скомпилирован: при правке дизайна можно менять обычный CSS,
отдельная сборка Tailwind для текущих классов не требуется.
app/assets-inline.ts генерируется при сборке из DOCX; вручную его править не нужно.

Интернет нужен для npm install и чтения внешних материалов. Готовый HTML
не загружает библиотеки с CDN, не вызывает API и не содержит ключей аккаунта.
Content Security Policy запрещает сетевые запросы приложения (connect-src 'none').

Формат прогресса:
{ "format": "cpp-roadmap-progress", "version": 1, "exportedAt": "ISO date",
  "entries": [{ "id": "0.1", "status": 2, "notes": "", "updated_at": "ISO date" }] }
Статусы: 0 — не начато, 1 — изучаю, 2 — пройдено.
Коды тем устойчивы: при изменении содержания сохраняйте их для совместимости.
Прогресс хранится под ключом cpp-roadmap-offline-v1 в localStorage, резервная
HTML-копия дополнительно содержит JSON в элементе roadmap-seed.

Свободно редактируй собственный код и учебный план. У сторонних компонентов
сохраняются их лицензии; тексты включены в THIRD_PARTY_NOTICES.txt.
Публикации и книги по внешним ссылкам не включены в поставку: их права сохраняются
за соответствующими авторами и издателями.

Никакого собственного сервера или базы данных для текущей версии не требуется.
Для размещения на твоём сервере достаточно раздавать готовый HTML как статический
файл. Прогресс останется локальным для каждого браузера.
